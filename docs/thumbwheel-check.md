# サムホイールと OLED の実機確認

サムホイールを Alps EC05E1220401（中空シャフトのロータリーエンコーダー）で読む構成と、LCSC の OLED モジュールを、実物の部品で確かめる手順です。設計の経緯は [docs/specs/thumbwheel-encoder.md](specs/thumbwheel-encoder.md) の手順表のステップ 10 にあります。各項目の結果は README の「発注・組み立て前の確認事項」に記録します。

確認は次の順に進めます。六角ピンの寸法が決まらないとホイールを印刷できず、ホイールがないと回転の確認ができないからです。

1. 六角ピンのはめあい（エンコーダー単体と試し印刷）
2. 基板の差し込み（3D プリント版のトレイ、基板、ホイール）
3. 回す向き（ファームウェアを書き込んだ基板）
4. クリックと送りの対応、クリックの手触り
5. OLED の動作と高さ

## 1. 六角ピンのはめあい

ホイール上面の六角ピンは、エンコーダーの六角穴（対辺 1.72 mm）に差し込んで回転部を回します。ピンの対辺は今 1.66 mm で、穴にすき間をもって入る寸法です。この寸法では、3D プリンターがピンの角を丸めるぶん、ピンが穴の中で空回りします。そこで、ピンを穴へ圧入する形に変えます。どの形と太さがよいかは印刷機によって変わるので、試し印刷で決めます。

`case/print/pin-test-all.stl` は、形の違うピン 25 本を 4 列に並べた板です（77 × 70 mm）。列ごとの板（`pin-test-straight.stl`、`pin-test-tapered.stl`、`pin-test-lobed.stl`、`pin-test-round.stl`）もあります。ピンの高さ、根元の掘り下げとフィレット、先端の面取りは、ホイールのピンと同じです。各ピンの下に、ピンの番号が浮き出ています。ホイールと同じ条件で印刷します（同じ材料、同じ層の高さ、ピンを上に向ける）。

| 番号 | 形 | 寸法 |
| --- | --- | --- |
| 11〜17 | まっすぐな六角柱 | 対辺 1.66、1.70、1.74、1.78、1.82、1.86、1.90 mm。11 は今のホイールと同じ |
| 21〜24 | 先細りの六角（ゆるい勾配） | 先端の対辺から、回転部の入口での対辺まで太くなる。1.60 → 1.76、1.64 → 1.80、1.68 → 1.84、1.72 → 1.88 mm |
| 25、26 | 先細りの六角（きつい勾配） | 1.60 → 1.90、1.66 → 1.96 mm |
| 31〜36 | 角だけ張り出した六角 | 平らな面は対辺 1.66 mm で穴に当たらない。角の半径が 0.98、1.00、1.02、1.04、1.06、1.08 mm（穴の角は 0.99 mm） |
| 41〜46 | 丸い軸 | 直径 1.74、1.78、1.82、1.86、1.90、1.94 mm。穴の平らな面の中央 6 か所に当たる |

どの形も、数字が大きいほどきつくなります。確認は次の順に進めます。

1. エンコーダーの六角穴には向きがあり、基板と反対の面（対辺 1.73 mm の側）からピンを差し込みます。JLCPCB で実装した基板なら、裏面で下を向いたエンコーダーへ、そのまま下からピンを差し込めます。
2. 列ごとに、数字の小さいピンから順に押し込みます。回転部の入口がピンの根元のフィレットに近づくまで（板の上面から約 0.3 mm）入れば、奥まで入っています。
3. 入ったピンごとに、エンコーダーの本体を指で押さえて板を左右にひねり、クリックを 2〜3 個送ります。ピンが穴の中で滑らないか、クリックの前にガタがないかを確かめます。
4. 抜いて、もう一度差し込みます。2 回目でもゆるまないかを確かめます。
5. 次の 4 点を記録します。
   - 滑らずに回せたピンの番号
   - 押し込むのに要った力の感触（指で入る、強く押せば入る、入らない）
   - 抜き差しのあとの変化
   - 折れたピンの番号

基板を筐体に入れるとき、ホイールのピンはエンコーダーに下から押し込まれます。押し込む力は基板とエンコーダーの半田付けにかかるので、強く押さないと入らないピンは候補から外します。

ドラム式ダイヤルのエンコーダー（EC10E1220505、穴の対辺 1.73 mm）にも、同じ板で確かめられます。ドラムは光造形で作るので、FDM の結果がそのまま当てはまるとは限りません。

結果が決まったら、選んだ番号の形と寸法を、Fusion の設計（`nrsk-<side>-case`）のホイールとドラムのピンに反映します。試し印刷の寸法は `gen/pin_test.py` にあります。

## 2. 基板の差し込み（3D プリント版）

3D プリント版では、基板を奥へ滑らせて、2 つの USB-C の差込口を奥の壁のトンネルに入れます。このとき、基板の裏に付けたエンコーダーの下面は、ホイールの六角ピンの先端から約 0.3 mm 上を通ります。

1. トレイの床の軸にホイールを差し、ホイールが軽く回ることを確かめます（軸とのすき間は半径方向に 0.2 mm）。
2. 基板を差込口のトンネルへ滑り込ませます。エンコーダーがピンに引っ掛かるかを見ます。引っ掛かる場合は、ホイールのある角を少し持ち上げて滑らせます。
3. 基板をボスまで下ろします。ピンが穴に入らないときは、ホイールの縁を指で少し回して向きを合わせます。
4. ネジを締めたあと、ホイールを 1 回転させ、こすれや重くなる位置がないかを確かめます。
5. 記録すること：角を持ち上げずに通ったか、持ち上げれば通ったか、通らなかったか。下ろしたときにピンが穴に入ったか。回したときの引っ掛かりの有無。

## 3. 回す向き

README の「ファームウェア」の節の手順で `nrsk_default.uf2` を左右に書き込みます。内側の USB-C どうしを C-C ケーブルでつなぎ、片方の外側の USB-C を PC につなぎます。

1. 左のホイールを、上から見て時計回りに 1 クリック回します。音量が上がれば正しい向きです。
2. 右のホイールを上から見て時計回りに 1 クリック回します。長いウェブページなどを開いておき、下へ 1 ページ進めば正しい向きです。
3. USB を反対側の半分につなぎ替えて、もう一度 1 と 2 を確かめます。USB をつないでいない側のホイールが効くことも、ここで確かめます。
4. 記録すること：左右それぞれ、時計回りで送られたキー（音量の上下、ページの上下）。

向きが逆の場合は、`gen/make_qmk.py` のエンコーダーの `pin_a` と `pin_b` を入れ替え、ファームウェアを作り直します。左右は同じ部品を同じ向きに付けているので、逆になるときは左右とも逆になるはずです。片側だけが逆のときは、その側の配線か半田付けを疑います。

## 4. クリックと送りの対応

エンコーダーは 1 回転 12 クリックで、1 クリックごとに A 相と B 相の信号がちょうど 1 周期進みます。ファームウェアは 1 周期で 1 回だけキーを送ります。

1. キー入力を表示するページ（QMK Configurator のキーテスター、`https://config.qmk.fm/#/test`）を開きます。右のホイールが送る Page Up と Page Down は、ここで回数を数えられます。左のホイールの音量は、画面に出る音量の表示で数えます。
2. 1 クリックずつ 12 回回し、送りが 12 回出ることを確かめます。逆向きにも同じように確かめます。
3. ホイールをクリックの山の手前まで回し、山を越えずに戻します。このとき送りが出ないことを確かめます。山の手前で何度か往復させても同じです。
4. 速く回したとき（1 秒に 1 回転ほど）に、送りの抜けが目立たないかを見ます。
5. 手触りを確かめます。エンコーダーのクリックトルクは 1.6 ± 1.3 mN·m で、ホイールの縁では約 0.11 N（ばらつきの範囲で 0.02〜0.2 N）にあたります。クリックの区切りがわかるか、軽すぎて意図せず回らないかを見ます。
6. 記録すること：12 クリックで送られた回数（左右、両方向）、山の手前で戻したときの送りの有無、速く回したときの様子、手触りの感想。

1 クリックで送りが 2 回以上出る場合や、2 クリックで 1 回しか出ない場合は、QMK の `resolution`（デフォルト値 4）を見直します。クリックが軽すぎる場合は、ホイールの直径を小さくする案を別件として検討します（仕様書の「やらないこと」の 1 つ目）。

## 5. OLED の動作と高さ

BOM の先頭の購入先は LCSC の HS91L02W2C01（C5248081）です。LCSC の製品ページの写真ではピン順が GND/VCC/SCL/SDA ですが、3.3 V で動くかとピンヘッダが付くかは書かれていません。

1. 半田付けの前に、モジュールの裏の印字でピン順を確かめます。基板のパッドの順（GND/VCC/SCL/SDA）と同じかを見ます。
2. モジュールに電圧変換の部品（3 端子のレギュレーター）が載っているかを見ます。載っていれば、3.3 V で動かない場合があります。
3. 基板に付けて電源を入れ、USB をつないだ側にレイヤーと Caps Lock、もう一方に WPM が表示されることを確かめます。
   文字の向きも見ます。モジュールは左右とも同じ向き（ピンヘッダが下）に付くので、逆さまなら左右とも逆さまです。その場合は `gen/make_qmk.py` の `OLED_ROTATION_270` を `OLED_ROTATION_90` に変え、`keymap.c` を作り直します。
4. ピンヘッダの黒い樹脂スペーサーを外して半田付けしたあと、基板の上面からガラス上面までの高さを測ります。設計では 2.5 mm です。高いとカバーに当たり、低いとカバーとのすき間が両面テープ（0.5 mm）より大きくなります。
5. 記録すること：ピン順、ピンヘッダの有無、3.3 V での表示の有無、文字の向き、ガラス上面の高さ。
