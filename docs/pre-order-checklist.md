## 実物で確かめるまで残るリスク

次の 5 つは、設計データだけでは確かめられません。影響の大きい順に並べています。

| 未確認のこと | 合わなかったときの影響 | 注文前にできる対処 |
| --- | --- | --- |
| ホットスワップソケットのフットプリント（Kailh CPG151101S11 の寸法で作った自作品） | ソケットが付かず、基板を作り直す | ソケットが手元にあれば、`fab/<side>/nrsk-<side>-assembly-back.pdf` を原寸で印刷して当てる |
| USB-C の回転の補正値 | USB-C が逆向きに実装され、ケーブルが挿さらない | JLCPCB の配置プレビューで向きを見る（前の節） |
| LCSC の OLED（HS91L02W2C01）のピン順と 3.3 V での動作 | VCC と GND が逆なら OLED が壊れる。動かなければ買い直す | 遊舎工房の OLED にするか、届いたときに裏の印字でピン順（GND/VCC/SCL/SDA）を確かめる |
| ホイールの六角ピンとエンコーダーのはめあい | ホイールを印刷し直す | ホイールの前に `case/print/pin-coupon.stl` を同じ条件で印刷し、ピンの太さを決める |
| ファームウェアの実機での動作 | 基板の不良と区別しにくい | `qmk compile -kb nrsk -km default` が通ることは確認済み。実機は基板が届いてから |

届いたあとの確認の手順は [thumbwheel-check.md](thumbwheel-check.md) にあります。

## 注文の順番と注文先

注文は 2 回に分けます。基板に不具合があると筐体の寸法も変わる可能性があるので、筐体の材料は基板を確かめてから注文します。

1. 筐体の版を決める。A（3D プリントのトレイ + 透明アクリルのプレート）、B（すべて 3D プリント）、アクリル版のどれか。版によってネジとアクリルが変わる
2. 先に注文する：JLCPCB の基板（左右 2 枚ずつ）、LCSC の部品、キーキャップ。基板の実装と海外のキーキャップは届くまでの日数が長い
3. 届いたら、ソケット、OLED、ホイール、USB-C の向きを確かめる
4. あとで注文する：はざいやのアクリル、筐体用のネジ。六角ピンの太さを決めてからホイールを印刷する

| 注文先 | 買うもの | 順番 |
| --- | --- | --- |
| JLCPCB | 基板と裏面の部品実装（左右別の注文） | 先 |
| LCSC | OLED 2、キースイッチ 85、ソケット 90、ドラム式ダイヤルのエンコーダー EC10E1220505 5（5 個単位）、USB ケーブル（PC 用）1 | 先 |
| JLC3DP などの造形サービス | ドラム式ダイヤルのドラム（光造形の樹脂） | あと |
| Signature Plastics | DSA キーキャップ 1.25 u、1.75 u、2.25 u | 先（関税と消費税がかかる） |
| 遊舎工房 | DSA キーキャップ 1 u、1.5 u、2 u、スタビライザー、左右接続用の C-C ケーブル | 先 |
| LCSC、MonotaRO | 筐体の版に合うネジ、インサート、ゴム足 | あと |
| はざいや | プレート、枠、底板、OLED カバー、RP2040 の窓の蓋のアクリル | あと |
| カインズなど | OLED カバーと窓の蓋に使う透明両面テープ（0.5 mm） | あと |

価格と在庫は 2026-10-10 時点の値です。注文の直前に各ページで確かめます。

## 取り扱いの注意と参照ファイル

- 左右接続用の USB-C（内側の口）を、PC や充電器につながない。この口の VBUS には、キーボードに電源が入っている間 5 V が出ている
- 左右接続には、データ通信に対応した C-C ケーブルを使う。充電専用のケーブルでは左右が通信しない
- RP2040（0.4 mm ピッチの QFN）と USB-C（0.5 mm ピッチ）は手半田に向かないので、JLCPCB の実装を使う
- 3D プリントのトレイは右が幅 197.5 mm ある。造形範囲が 220 mm 角以上のプリンターを使う
- はざいやでは、プレートのスイッチ穴（14.0 mm 角）を切り幅の補正ありで切るかを注文時に確かめる
